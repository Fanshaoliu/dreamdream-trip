# 意法瑞旅行助手网页

这是一个基于 `itinerary.md` 制作的单文件旅行助手，主文件是 `index.html`。

## 使用方式

直接用浏览器打开 `index.html` 即可。页面使用 React、Tailwind 和 globe.gl 的 CDN 资源，行程数据和工具数据都已经内置在文件里。

出发前建议在手机上联网打开一次页面，让浏览器缓存 CDN 资源；之后大部分内容即使网络较差也能查看。

## 手机加到主屏幕

### iPhone Safari

1. 打开网页。
2. 点击分享按钮。
3. 选择“添加到主屏幕”。
4. 命名为“旅行助手”。

### Android Chrome

1. 打开网页。
2. 点击右上角菜单。
3. 选择“添加到主屏幕”或“安装应用”。

## 功能

- 欧洲路线地图展示米兰、多洛米蒂、威尼斯、佛罗伦萨、罗马、巴黎、采尔玛特、施皮茨、卢塞恩等节点。
- 点击地图上的 D1-D18 节点，可直接查看当天交通、住宿、景点和提醒。
- 每日行程时间线，按国家配色，支持折叠展开。
- 自动根据日期高亮当天行程。
- 景点一键跳转 Google Maps。
- 汇率换算：人民币、欧元、瑞士法郎。
- 多时区时钟：北京、意大利、法国、瑞士。
- 应急常用语：中文、意大利语、法语、德语。
- 紧急电话：欧洲统一 112 和各国常用紧急号码。
- 抢票清单：斗兽场、梵蒂冈、最后的晚餐、卢浮宫等。
- 常识提醒：小费、退税、饮水、卫生间、防盗、山地徒步。
- 交通、票务、天气官网快捷入口。

## 出发前 Checklist

- 打开一次网页，确认 3D 地球和样式能加载。
- 手机浏览器添加到主屏幕。
- 在 Google Maps 下载米兰、威尼斯、佛罗伦萨、罗马、巴黎、瑞士山区离线地图。
- 更新网页里的汇率默认值。
- 勾选已完成的抢票项目。
- 保存护照、保险、机票、酒店订单、火车票和门票的离线 PDF。
- 多洛米蒂和瑞士徒步前一天确认天气、缆车、公交末班车。

## GitHub Pages 部署

推荐把 `index.html` 放在仓库根目录，开启 GitHub Pages：

1. 新建 GitHub 仓库，例如 `travel-helper`。
2. 上传 `index.html` 和 `README.md`。
3. 进入仓库 `Settings` -> `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`。
6. 保存后等待 1-2 分钟，访问 `https://你的用户名.github.io/travel-helper/`。

不要把 GitHub 密码发给任何人。若需要命令行推送，建议使用 GitHub Personal Access Token 或 GitHub CLI 的网页登录方式。
